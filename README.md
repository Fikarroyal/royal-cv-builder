## Tentang Royal CV Builder

**Royal CV Builder** adalah aplikasi web untuk membuat CV (resume) secara cepat dan nyaman. Isi data kamu di editor, lihat hasilnya langsung di pratinjau, pilih template yang paling cocok, cek kesiapan CV terhadap sistem ATS, lalu unduh sebagai PDF — semuanya dalam satu tempat.

Dirancang untuk fresh graduate, profesional, hingga pencari kerja yang ingin tampil percaya diri di mata recruiter.

## Cara Menjalankan

Tidak perlu instalasi dependensi. Cukup clone dan buka di browser.

```bash
# 1. Clone repository
git clone https://github.com/Fikarroyal/royal-cv-builder.git

# 2. Masuk ke folder proyek
cd royal-cv-builder
```

Lalu pilih salah satu cara berikut:

- **Langsung:** buka file `index.html` di browser favoritmu.
- **Lewat server lokal** (opsional):

  ```bash
  python -m http.server 8000
  ```

  Kemudian buka `http://localhost:8000`.

> [!NOTE]
> Koneksi internet dibutuhkan agar ikon, font, dan pustaka PDF dapat dimuat dari CDN.
